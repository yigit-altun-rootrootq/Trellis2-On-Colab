# 🚀 TRELLIS.2 on Google Colab

Run **Microsoft TRELLIS.2** easily on **Google Colab** with this ready-to-use notebook.

This project is designed to make the TRELLIS.2 setup process simpler and more accessible. Instead of manually configuring the environment, installing dependencies, and dealing with compatibility issues, you can use the prepared Google Colab notebook to get started more easily.

TRELLIS.2 is a powerful 3D generation system capable of creating detailed 3D assets from images. This notebook provides a practical environment for experimenting with the TRELLIS.2 pipeline directly in Google Colab.

## ⚠️ Important Notes

TRELLIS.2 can require significant GPU resources depending on the generation settings and model configuration.

For the best experience:

- Enable a GPU runtime in Google Colab.
- Follow the notebook cells in order.
- Make sure you have access to any required Hugging Face models.
- Higher-quality generations may require more VRAM and processing time.
